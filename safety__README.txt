ҚАУІПСІЗДІК САБАҚТАРЫ — 1–11 СЫНЫП БӨЛЕК ҚАЛТАЛАРДА

Ашу реті: safety.html → сынып қалтасы → тақырып → тапсырмалар мен бейнематериалдар.

ҚҰРЫЛЫМЫ
index.html / safety.html — барлық сыныптың басты беті.
grade-1 … grade-11 — әр сыныптың жеке қалтасы.
Әр қалтадағы index.html — осы сынып тақырыптарының тізімі.
Әр қалтадағы topic-01.html … — тақырыптың жеке парақшасы.
assets/style.css — ортақ қазақы безендіру.
safety-source.pdf — бастапқы құжат.

ДАЙЫН САЙТҚА КІРІКТІРУ
1. ZIP-ті шығарыңыз.
2. Репозиторийде safety атты жаңа қалта жасаңыз.
3. Жинақтың бүкіл мазмұнын (қалталарымен бірге) сол safety қалтасына жүктеңіз.
4. Өз сайтыңыздың басты бетіне қосыңыз:
<a href="safety/safety.html">Қауіпсіздік сабақтары</a>
5. Commit changes басып, GitHub Pages жаңаруын күтіңіз.

ЖЕКЕ САЙТ РЕТІНДЕ
Жинақтың мазмұнын бос репозиторий түбіріне жүктеңіз. Settings → Pages арқылы тиісті branch / root таңдаңыз. Басты бет index.html арқылы ашылады.

Компьютерде қарау үшін safety.html файлын браузермен ашыңыз. Беттер, сыныптар мен тақырыптар JavaScript-сіз де жұмыс істейді. Бейнелер мен сыртқы ресурстарға интернет қажет. Қалталар мен файлдардың атауын және өзара орналасуын сақтаңыз.

Құжаттағы 1–11-сыныптың 124 сабағы берілген. Бейнесілтемелер бастапқы PDF-тен алынған, сыртқы бейнелердің ойнатылуы бұл ортада тексерілмеді. Бейне жоқ тақырыптарға бөтен бейнелер қосылған жоқ.

ЖАҢАРТЫЛҒАН ОҚУ ҚҰРЫЛЫМЫ
Әр тақырып үш бөлек HTML беттен тұрады:
- topic-01.html: тақырыптық лекция, мақсат, үш қауіпсіз қадам, бейнематериалдар.
- topic-01-tasks.html: A1 жағдаяттық, A2 жұптық, A3 топтық тапсырмалар, мұғалімге бағдар және бастапқы материал.
- topic-01-feedback.html: кері байланыс, өзіндік тексеру, жазба өрістері.
Барлығы: 124 лекция, 124 тапсырма парағы (372 жаңа тапсырма), 124 кері байланыс парағы.
Қосымша тапсырмалар әр сыныптың күрделілік деңгейіне сай әдістемелік толықтыру ретінде берілген. Жеке оқиғаларды ашу талап етілмейді. Тапсырмаларды бір отырыста не бөлек орындауға болады; көрсетілген минуттар міндетті сабақ ұзақтығы емес.
Кері байланыс жауаптары тек осы браузерде сақталады. Ортақ компьютерде «Жауаптарды тазарту» батырмасын басыңыз. Серверге дерек жіберілмейді.
